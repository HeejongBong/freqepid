# `freqepid`: code package for the methods, examples and data in "Frequentist Inference for Sei-mechanistic Epidemic Models with Interventions" [[1](#BVW24)]

This repository consists of 
1. Python package `freqepid` which implements the methods in [[1](#BVW24)]
2. the data from Delphi COVIDcast ([[3](#Delphi21)]), analyzed in [[1](#BVW24)]. 
3. the IPython notebooks of the reproducible code scripts for the simulations and the COVID-19 data analysis in [[1](#BVW24)].

## Install

### Prerequisite

Package `freqepid` requires
1. Python >= 3.5, 
2. `numpy` >= 1.8,
3. `matplotlib` and `scipy`.

Some code scripts in this repository require installation of `R`,
1. the `pandas` Python package, 
2. the `tidyverse`, `arrow`, `extrafont` R packages and
3. the [`epidemia`](https://imperialcollegelondon.github.io/epidemia/) R package.

### `Git` clone

Clone this repo through github:
```bash
git clone https://github.com/HeejongBong/freqepid.git
```

### Package installation

Install package `freqepid` using the following bash script:
```bash
pip install .
```

## Simulation study (Section 7.1, [[1](#BVW24)])

### Point estimate
The relevant files are available in `/examples/Simulation Study/`. We fitted two models: (i) negative binomial models and (ii) Gaussian models for $I_t$ and $Y_t$. The data were generated by the code script `Simulation Data.ipynb`. The genrating and infection-to-death distributions $g$and $\pi$ are available in `/data/GPi.npz`, which are depicted in Fig. 2. (The same file is also available in the other directories in `/examples/`.) The exact copy of the simulation data for the figures in the paper is available in `/examples/Simulation Study/data/`. The code scripts for the analyses are
- `Simulation Study - epidemia nbinom.ipynb`: using the Bayesian approach by `epidemia` under model (i), which generate Fig. 3(d--f).
- `Simulation Study - freqepid nbinom.ipynb`: using the maximum likelihood estimation by `freqepid` under model (i), which generates Figs. 3(a--c) and C.4.
- `Simulation Study - freqepid normal.ipynb`: using the maximum likelihood estimation by `freqepid` under model (ii), which generates Figs. 4 and C.3.

### Coverage
The relevant files are available in `/examples/Coverage Study/`. We considered only the negative binomial models. The data were generated by the code scripts `Simulation Data - beta_*.ipynb` respective to the 5 values of $\beta$ shown in Table 1. The exact copy of the simulation data for the figures in the paper is available in `/examples/Coverage Study/data/`. The code scripts for the analyses are
- `Coverage Study - freqepid nbinom, beta_*.ipynb`: using the maximum likelihood estimation by `freqepid`, which generates the first row of Table 1.
- `Coverage Fit - epidemia nbinom, beta_*.ipynb` and `Coverage Study - epidemia nbinom, beta_*.ipynb`: using the Bayesian approach by `epidemia`, which generate the second row of Table 1.

### Shrinkage
The relevant files are available in `/examples/Shrinkage Study`. We considered only the case where there was a phantom variable. The data were generated by the code scripts `Simulation Data - ebcr_*.ipynb` respective to the 3 different sets of parameters shown in Fig. 5. The exact copy of the simulation data for the figures in the paper is available in `/examples/Shrinkage Study/data/`. The code scripts for the analyses are
- `Simulation Study - freqepid, ebcr_*.ipynb`: using the maximum likelihood estimation by `freqepid`, which generates Fig. 6 and the first row of Table 2.
- `Simulation Fit - epidemia, ebcr_*.ipynb` and `Simulation Study - epidemia, ebcr_*.ipynb`: using the Bayesian approach by `epidemia`, which generate Fig. 7 and the second row of Table 2.

## COVID-19 data analysis (Section 7.2, [[1](#BVW24)])
The relevant files are available in `/examples/Experimental Data Analysis/`. The data are available in `/examples/Experimental Data Analysis/data/CovidCastStateAdj_2.feather`. The original data are obtained via the [Delphi Epidata API](https://cmu-delphi.github.io/delphi-epidata/api/covidcast.html). The code scripts for the analyses are
- `Exp. Analysis - delphi, collect data.ipynb`: the collection of the COVID-19 data using the `covidcast` Python API [[3](#Delphi21)].
- `Exp. Analysis - delphi, adjust weekend effects.ipynb`: the preprocessing step used to correct for the weekend effect, which shows fewer deaths reported on Saturdays and Sundays. This code script generates Fig. C.5.
- `Exp. Analysis - delphi.ipynb`: using the maximum likelihood estimation by `freqepid`, which generates Figs. 8 and 9. This code script also collects results from `Exp. Fit - *.ipynb` to generate Figs. 10 and 11.
- `Exp. Fit - epidemia, delphi.ipynb` and `Exp. Fit - epidemia, delphi, nonsrhink.ipynb`: using the Bayesian approach by `epidemia` with priors given in [[2](#BFFGMS23)], which generates results for Fig. 10(b). The second code script fits each state separately, resulting in nonshrinkage estimates.
- `Exp. Fit - epidemia, delphi.ipynb` and `Exp. Fit - epidemia, delphi, nonsrhink.ipynb`: using the Bayesian approach by `epidemia` with less informative priors, which generates results for Fig. 10(c). The second code script fits each state separately, resulting in nonshrinkage estimates.
